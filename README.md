# 112 İstatistik Merkezi — Dağıtım

Bu repo, **kaynak kodu içermez**. Sadece uygulamanın güncelleme kontrolü ve
tek dosya (standalone) HTML dağıtımı için kullanılan iki dosyayı barındırır:

- `manifest.js` — mevcut en güncel sürüm bilgisi (uygulama içindeki
  "yeni sürüm var" bildirimi bu dosyayı okur).
- `112-istatistik-merkezi.html` — indirilebilir, tek dosyalık, çalışan
  uygulama kopyası.

Kaynak kod özel (private) `istatistik-merkezi-112` reposunda tutulur.
